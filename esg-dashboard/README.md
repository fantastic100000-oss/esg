# ESG 데이터 플랫폼 (MVP)

API 연동 없이 브라우저에서 동작하는 ESG 데이터 관리 프로토타입입니다. 모든 데이터는
`localStorage`에 저장되며, 최초 실행 시 4개 사업장(본사·CK·물류센터·급식사업장)의
최근 6개월 샘플 데이터가 자동 생성됩니다.

## 실행

```bash
npm install
npm run dev
```

## 기술 스택

- React + TypeScript + Vite
- Tailwind CSS v4
- react-router-dom (해시 라우팅)
- Recharts (차트)

## 주요 화면

- **대시보드** (`/`): 핵심 지표 요약, 전월 대비 증감률, 사업장별 비교/월별 추이 차트
- **ESG 데이터 입력** (`/entry`): 사업장·월별 실적 입력, 자동 배출량 계산 미리보기, 실시간 검증
- **데이터 관리·승인** (`/records`): 전체 데이터 테이블(이상치·누락·증빙 표시) + 승인 워크플로우
- **GRI 공시 매핑** (`/gri`): 입력 데이터를 GRI 302-1, 303-3, 305-1, 305-2, 306-3 항목에 매핑

## 자동 계산

`src/constants/index.ts`의 `EMISSION_FACTORS`에 정의된 예시 배출계수(임의값, 실제 국가
고시계수 아님)를 기준으로 Scope 1(도시가스·차량연료)/Scope 2(전력) 배출량을 계산합니다.

## 데이터 검증 규칙

- 전월 대비 ±20% 이상 변동 시 이상치로 표시
- 사업장×월 조합 중 레코드 자체가 없으면 누락 데이터로 표시
- 증빙파일명 미입력 시 경고 표시

## 참고

- 실제 백엔드/외부 API 연동 없음 (완전한 프런트엔드 전용 프로토타입)
- 우측 상단 "샘플 데이터 초기화" 버튼으로 언제든 초기 샘플 데이터로 되돌릴 수 있습니다.
